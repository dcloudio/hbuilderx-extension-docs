# CLI uni-app / uni-app x 发行 - App-Harmony-本地打包@packAppHarmony

> HBuilderX cli 命令行工具

通过 CLI 对鸿蒙平台进行本地打包，支持 **uni-app**、**uni-app x** 项目。

> **适用项目**：uni-app、uni-app x（`app-harmony`）。完整平台对照见 [CLI 概述](/cli/README?id=project-platform)。

## 命令说明

### pack app-harmony

对鸿蒙平台进行本地打包

**参数：**

| 参数      | 说明           |
| --------- | -------------- |
| --help    | 显示命令帮助   |
| --project | 必填，项目名称 |

**使用示例：**

```shell
# 查看命令帮助
cli pack app-harmony --help

# 对鸿蒙平台进行本地打包
cli pack app-harmony --project 项目名称
```

**注意事项：**

> 首先, 需要启动 HBuilderX. (进入 HBuilderX 安装目录根目录, 终端输入 `cli.exe open`)
